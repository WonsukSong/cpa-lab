# CPA Lab

과목별 인터랙티브 CPA 학습서의 비밀번호 보호 검토판입니다.

- 8권의 과목별 책과 23개의 개념 실험
- 첫 화면에서 책을 선택한 뒤 비밀번호로 학습 내용을 열 수 있습니다.
- 학습 본문은 암호화되어 있으며 비밀번호는 저장소에 포함하지 않습니다.
- 학습 진도는 방문자의 브라우저에 저장됩니다.

## 검토판 범위

2026-10-19 확인 자료를 반영한 개념 학습 보조 자료입니다. 2027 시험의 최종 시행계획과 적용 기준은 추후 확인이 필요합니다. 세법과 기업법의 일부 실험은 명시된 가상 조건을 사용하며, 실제 2027 법령판이나 전 범위 수험서를 대체하지 않습니다.
