# CPA Lab

과목별 CPA 웹북의 비밀번호 보호 검토판입니다.

- 8권의 책, 본문 23개 장
- 도입 사례·개념 본문·공식의 원리·비교표
- 기초·응용·시험형 풀이 예제 69개
- 해설을 제공하는 복습 문제 69개
- 본문과 예제 뒤에서 확인하는 인터랙티브 실험 23개
- 본문 검색, 장 내부 이동, 단계별 풀이 펼치기, 브라우저별 학습 기록

## 접속

https://wonsuksong.github.io/cpa-lab/

## 검토 범위

2026-10-19 확인한 공식 자료와 개념·계산을 반영한 보조 학습 자료입니다. 직접 제작한 시험형 예제이며 실제 기출문제가 아닙니다. 2027 시험의 최종 시행계획과 적용 기준은 추후 확인이 필요합니다. 세법의 세율·구간과 기업법 의결 실험의 문턱은 가상입니다. 기업법 본문은 확인한 시행본의 일부 기본 조문만 한정 설명합니다. 전 범위 수험서나 2027 확정 법령판을 대체하지 않습니다.
