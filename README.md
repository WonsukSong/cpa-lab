# CPA Lab

비밀번호로 공유하는 한국어 CPA 학습 웹북입니다.

- 과목별 교재 8권과 별도 예상문제집 1권
- 읽기 72장: 기존 본문·실험 23장 + 추가 읽기 49장
- 풀이 예제 239개·장별 복습 239개(객관식 자동채점과 서술형 자기점검 구분)
- 기존 인터랙티브 실험 23개
- 2027 수험 안내: 1차·2차 과목과 책의 연결, 권장 순서, 26개 공식 분야 묶음의 비중·현재 포함·추가 학습 범위
- 별도 예상문제집 56문항, 기존 암호화 문제 피드 유지

## 접속

https://wonsuksong.github.io/cpa-lab/

첫 화면의 책을 선택해 기존 공유 비밀번호로 엽니다. 서재 안의 **2027 수험 안내**에서 시험 단계별 학습 경로를 확인합니다. 학습 기록은 기존과 같은 주소의 브라우저에 보관됩니다.

## 수험생 관점 보강

배포본 51장 이후 미반영 13장을 통합하고 8장을 추가해 72장으로 확장했습니다. 추가 8장은 자산손상·충당부채, 제조간접원가 차이·전부/변동원가 이익, 이항옵션, 성장·실업, 감사수임·중요성, 지방세, 성격·몰입·협상, 주식양도입니다. 총 추가 풀이 예제와 복습은 각각 63개입니다.

2027 공식 사전예고에 따라 1차 경영학은 재무관리 책과 경영학 책을 함께 읽습니다. 2차 재무회계Ⅰ·Ⅱ의 내용은 재무회계 책에 함께 있습니다. 정부회계는 1차 범위로 구분합니다. 수험 안내에 남은 심화 범위를 명시하며 전 범위 기본서 완성을 주장하지 않습니다.

## 적용연도와 근거

2026-10-19 확인한 현행 자료와 [2027 공식 출제범위 사전예고](https://www.fsc.go.kr/no010104/86803)를 대조한 학습 자료입니다. 최종 시행계획은 [금융위원회 안내](https://www.fsc.go.kr/no010101/87628)에 따라 2026년 11월 공고 예정입니다. 법령·기준의 시행일과 시험 적용일을 구분하며 최종 공고·정정 공고를 다시 확인해야 합니다.

세법의 가상 세율은 구조 연습용이며 실제 2027 세율표가 아닙니다. 기업법에서 공인회계사법·외부감사법 시행령 포함은 사전예고상 2028년부터입니다. 국제 회계·감사기준과 국내 채택·시험 적용은 별도로 확인합니다. 본문·문제는 자체 창작이고 공개 기출은 공식 원문으로 연결합니다.

## 검증 및 보호

장 경로·목차·검색·객관식 채점·서술 저장·학습 기록·인쇄 복원·시험 단계 선택을 DOM/VM에서 검증했습니다. 추가 수치의 별도 산술 검산 26건과 암호화·변조 거부 검증을 수행했습니다. 실제 브라우저의 시각·터치 검증은 별도입니다.

기존 비밀번호 확인 암호문과 RSA 공개키·개인키 쌍을 유지합니다. 갱신한 본문은 기존 잠금 해제 후 이용 가능한 키로 여는 암호화 판으로 보관합니다. 공개 저장소에는 암호문·공개키·공개 도구만 올리고 평문 교재·문제 원본·비밀번호·개인키는 올리지 않습니다.

문제 갱신은 [QUESTION_UPDATES.md](./QUESTION_UPDATES.md)를 따릅니다. GitHub Pages 게시 원본은 main 브랜치 루트입니다.

교재 화면의 Student’s Reading Review와 Exam Scope 검토 메모는 렌더링하지 않으며, 업데이트 참고용 주석과 내부 데이터로 보관합니다.
