# CPA Lab

비밀번호로 공유하는 한국어 CPA 학습 웹북입니다.

- 과목별 교재 8권과 별도 예상문제집 1권
- 읽기 51장: 기존 본문·실험23장 + 추가 읽기28장
- 풀이 예제176개·장별 복습176개(객관식 자동채점과 서술형 자기점검 구분)
- 인터랙티브 실험23개, 책별 권장 학습 순서·보강 진단·남은 범위
- 별도 예상문제집: 2026-10-19 보강판 기준56문항, 이후 검토한 문제를 정기 추가

## 접속

https://wonsuksong.github.io/cpa-lab/

첫 화면에서 책을 고른 뒤 전달받은 비밀번호로 엽니다. 본문·문제는 자체 창작이며 공식 기출은 원문 링크로 연결합니다.

## 학습과 검토

기존23장 전체를 읽고 공식 출제범위와 비교해 설명·예제·문제를 보강했습니다. 새 장에는 선수개념·본문·판단 흐름·기초·응용·시험형 풀이 예제·연습·출처를 배치했습니다. 기존 기록과 새 읽기·보강 기록, 예상문제집 기록을 구분해 저장합니다.

2026-10-19 확인한 현행 자료와 2027 출제범위 사전예고를 반영한 검토판입니다. 최종 시행계획·법령 및 기준의 시험 적용일 확인이 남아 있습니다. 각 책의 남은 범위를 표시하며 전 범위 기본서 완성을 뜻하지 않습니다. 가상 세율·실험 조건과 실제 법률 사례를 구분합니다.

## 문제 갱신

공개키로 암호화한 question-bank.enc.json을 갱신하면 기존 사이트에서 새 문제를 불러옵니다. 원본과 기존 문항 ID를 보존하며 절차는 [QUESTION_UPDATES.md](./QUESTION_UPDATES.md)에 기록했습니다.

공개 저장소에는 암호문과 공개키·공개 도구만 반영합니다. 비밀번호·RSA 개인키·평문 본문과 원본 문제은행·전체 소스는 포함하지 않습니다. GitHub Pages 게시 원본은 main 브랜치 루트입니다.
