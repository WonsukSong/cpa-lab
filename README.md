# CPA Lab

비밀번호로 공유하는 한국어 CPA 학습 웹북입니다.

- 교과서 8권: 본문 23장·풀이 예제 69개·복습 문제 69개·인터랙티브 실험23개
- 별도 예상문제집 1권: 초기24문제(8과목 × 객관식2 + 서술형1)
- 과목·난도·유형·오답 필터, 객관식 채점, 서술형 자가점검, 관련 본문과 출처

## 접속

https://wonsuksong.github.io/cpa-lab/

첫 화면에서 책을 고른 뒤 전달받은 비밀번호로 엽니다. 정기 추가 문제도 암호화되어 있으며 비밀번호와 개인키·평문 원본은 저장소에 포함하지 않습니다.

## 문제 갱신

공개키로 암호화한 `question-bank.enc.json`을 갱신하면 기존 사이트에서 새 문제를 불러옵니다. 원본은 별도로 유지하고 기존문항 ID를 보존합니다. 갱신·검토·배포의 절차는 [QUESTION_UPDATES.md](./QUESTION_UPDATES.md)에 기록했습니다.

## 검토 범위

2026-10-19 확인 자료와 개념·계산을 반영한 검토판입니다. 실제 기출문제나 출제 확률 예측이 아닙니다. 2027 시험 최종 시행계획과 적용 기준은 확인이 남아 있습니다. 세법의 가상 세율과 기업법의 가상 의결 문턱은 실제 2027 규정으로 사용하지 않습니다. 기업법 본문·문제의 실제 조문 사례는 해당 시행본과 명시한 제한 조건만 다룹니다.
